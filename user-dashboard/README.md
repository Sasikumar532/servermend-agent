# servermend-user-dashboard

React app for end customers: server list, score breakdown by category, findings, drift-review queue, remediation detail.

## Layout

```
user-dashboard/
├── src/
│   ├── pages/        # server list, server detail, finding detail
│   ├── components/    # severity pill, score chart, findings table
│   └── api/            # backend API client
└── package.json
```

## Status

Scaffold only — see the development roadmap for the milestone build order (D0–D3).

## Local run (once implemented)

```
npm install
npm run dev
```
